5.1 Complex Notation in Vibration Analysis

Before analysing the free damped response, we introduce a powerful mathematical tool: complex exponential notation, based on Euler’s identity. This will significantly simplify our calculations going forward.

Euler’s Identity

From Euler, we know:

\[e^{i\theta} = \cos\theta + i\sin\theta\]

For a time-varying angle \(\theta = \omega t\), this becomes:

\[e^{i\omega t} = \cos(\omega t) + i\sin(\omega t)\]

Therefore, a sinusoidal motion can be represented as either the real or imaginary part of a complex exponential:

\[\cos(\omega t) = \text{Re}\!\left(e^{i\omega t}\right), \qquad \sin(\omega t) = \text{Im}\!\left(e^{i\omega t}\right)\]

Why Is This Useful?

The real advantage appears when differentiating. If \(u(t) = Ue^{i\omega t}\), then:

\[\dot{u}(t) = i\omega\, U e^{i\omega t}, \qquad \ddot{u}(t) = -\omega^2\, U e^{i\omega t}\]

Differentiation becomes multiplication — an enormous simplification.

Recovering the Forced Response with Complex Notation

Replacing the excitation \(F_0\sin(\omega t)\) with \(F_0 e^{i\omega t}\) (we take the imaginary part of the solution at the end):

\[m\ddot{u} + c\dot{u} + ku = F_0 e^{i\omega t}\]

With \(u(t) = Ue^{i\omega t}\):

\[m(-\omega^2)Ue^{i\omega t} + c(i\omega)Ue^{i\omega t} + kUe^{i\omega t} = F_0 e^{i\omega t}\]

Dividing through by \(e^{i\omega t}\):

\[U\bigl(k - m\omega^2 + ic\omega\bigr) = F_0\]

\[U = \frac{F_0}{k - m\omega^2 + ic\omega}\]

To extract the amplitude, multiply numerator and denominator by the complex conjugate \((a - ib)\), where \(a = k - m\omega^2\) and \(b = c\omega\):

\[U = \frac{F_0}{a + ib}\cdot\frac{a - ib}{a - ib} = \frac{F_0(a-ib)}{a^2+b^2}\]

\[U = \frac{F_0\,a}{a^2+b^2} - i\,\frac{F_0\,b}{a^2+b^2}\]

Then we compute the modulus:

\[|U| = \sqrt{\left(\frac{F_0 a}{a^2+b^2}\right)^{\!2} + \left(\frac{F_0 b}{a^2+b^2}\right)^{\!2}} = \frac{F_0\sqrt{a^2+b^2}}{a^2+b^2} = \frac{F_0}{\sqrt{a^2+b^2}}\]

\[\boxed{|U| = \frac{F_0}{\sqrt{(k-m\omega^2)^2+(c\omega)^2}}}\]

This is exactly the same result from Class 4 — now obtained in a few lines. Complex notation is the standard tool in vibration analysis.

5.2 Free Vibration of a Damped System

We now turn to the free (unforced) response of the damped 1-DOF system. Using the dimensionless equation from Class 4 (with right-hand side equal to zero):

\[\ddot{u} + 2\zeta\omega_n\dot{u} + \omega_n^2 u = 0\]

General Trial Solution

To find the solution in all cases simultaneously, we propose the general trial solution:

\[u(t) = Ce^{st}\]

where \(s\) is a complex number to be determined. This is the most general trial function — depending on whether \(s\) is real or complex, it will represent exponential decay, oscillation, or both.

Substituting:

\[s^2 Ce^{st} + 2\zeta\omega_n s\, Ce^{st} + \omega_n^2 Ce^{st} = 0\]

Dividing by \(Ce^{st} \neq 0\):

ImportantCharacteristic Equation

\[\boxed{s^2 + 2\zeta\omega_n s + \omega_n^2 = 0}\]

The two roots of this equation completely determine the nature of the free response.

Applying the quadratic formula:

\[s = -\zeta\omega_n \pm \omega_n\sqrt{\zeta^2 - 1}\]

The term \(\sqrt{\zeta^2 - 1}\) changes character depending on \(\zeta\):

  • If \(0 < \zeta < 1\): \(\zeta^2 - 1 < 0\) → complex roots → oscillatory decay
  • If \(\zeta = 1\): \(\zeta^2 - 1 = 0\) → repeated real root → fastest non-oscillatory decay
  • If \(\zeta > 1\): \(\zeta^2 - 1 > 0\) → two distinct real roots → pure exponential decay

Case 1 — Underdamped System (\(0 < \zeta < 1\))

Since \(\zeta^2 - 1 < 0\), we write \(\sqrt{\zeta^2 - 1} = i\sqrt{1-\zeta^2}\). Defining the damped natural frequency:

\[\omega_d = \omega_n\sqrt{1-\zeta^2}\]

the two complex conjugate roots are:

\[s_{1,2} = -\zeta\omega_n \pm i\omega_d\]

The general solution is therefore:

\[u(t) = e^{-\zeta\omega_n t}\bigl[A\cos(\omega_d t) + B\sin(\omega_d t)\bigr]\]

or equivalently (introducing amplitude \(V\) and phase \(\psi\)):

ImportantUnderdamped Free Response

\[\boxed{u(t) = V\,e^{-\zeta\omega_n t}\,\cos(\omega_d t - \psi)}\]

  • The exponential envelope \(Ve^{-\zeta\omega_n t}\) causes the amplitude to decay toward zero.
  • The oscillatory part \(\cos(\omega_d t - \psi)\) produces a sinusoidal waveform at frequency \(\omega_d < \omega_n\).
  • Both \(V\) and \(\psi\) are determined by initial conditions.

Note that \(\omega_d < \omega_n\) because \(\sqrt{1-\zeta^2} < 1\). Damping lowers the oscillation frequency in addition to reducing the amplitude.

Case 2 — Critically Damped System (\(\zeta = 1\))

When \(\zeta = 1\), the discriminant vanishes and \(s = -\omega_n\) is a repeated root:

\[s^2 + 2\omega_n s + \omega_n^2 = (s + \omega_n)^2 \quad \Rightarrow \quad S_1 = S_2 = -\omega_n\]

Since the equation is second order, we need two independent solutions. The first is:

\[u_1(t) = A\,e^{-\omega_n t}\]

The second independent solution comes from the theory of repeated roots (Taylor expansion):

\[u_2(t) = Bt\,e^{-\omega_n t}\]

The complete critically damped solution is:

ImportantCritically Damped Free Response

\[\boxed{u(t) = (A + Bt)\,e^{-\omega_n t}}\]

Critical damping returns the system to equilibrium as fast as possible without any oscillation.

Case 3 — Overdamped System (\(\zeta > 1\))

When \(\zeta > 1\), both roots are real and distinct:

\[s_1 = -\zeta\omega_n + \omega_n\sqrt{\zeta^2-1}, \qquad s_2 = -\zeta\omega_n - \omega_n\sqrt{\zeta^2-1}\]

The general solution is:

ImportantOverdamped Free Response

\[\boxed{u(t) = A\,e^{s_1 t} + B\,e^{s_2 t}}\]

Since \(s_1 < 0\) and \(s_2 < 0\), both terms decay exponentially — the response is non-oscillatory and slower than critical damping.

Summary: The Three Damping Regimes

The discriminant \(\sqrt{\zeta^2-1}\) controls the qualitative behaviour. \(\zeta\) controls the qualitative motion of the system.

Regime \(\zeta\) Roots Response
Underdamped \(0 < \zeta < 1\) Complex conjugates Oscillatory decay
Critically damped \(\zeta = 1\) Real, repeated Fastest non-oscillatory decay
Overdamped \(\zeta > 1\) Real, distinct Pure exponential decay

5.3 Logarithmic Decrement

A key application of underdamped free vibration is experimental damping identification. Given measured free vibration data, we can extract \(\zeta\) from the ratio of successive peaks. The interactive below shows which peaks are being compared and computes \(\delta\) and \(\zeta\) live.

Code 
viewof zeta_ld = Inputs.range([0.02, 0.5], {value: 0.1, step: 0.01, label: "Damping ratio  ζ"})
viewof wn_ld   = Inputs.range([0.5, 10],  {value: 2.0, step: 0.5,  label: "Natural frequency  ωₙ  (rad/s)"})
viewof peak_n  = Inputs.range([1, 5],     {value: 1,   step: 1,    label: "Compare peak n  with peak n+1"})
Code 
wd_ld  = wn_ld * Math.sqrt(1 - zeta_ld**2)
Td_ld  = 2 * Math.PI / wd_ld
tEnd_ld = (peak_n + 2.5) * Td_ld
dt_ld  = tEnd_ld / 600

function u_ld(t) {
  return Math.exp(-zeta_ld * wn_ld * t) * Math.cos(wd_ld * t)
}

data_ld = Array.from({length: 601}, (_, i) => ({t: i * dt_ld, u: u_ld(i * dt_ld)}))

// Peak times: cosine peaks at t = n * Td
t1_ld = (peak_n - 1) * Td_ld
t2_ld = peak_n * Td_ld
u1_ld = u_ld(t1_ld)
u2_ld = u_ld(t2_ld)
delta_ld = Math.log(u1_ld / u2_ld)
zeta_from_delta = delta_ld / Math.sqrt(4 * Math.PI**2 + delta_ld**2)

Derivation

For two consecutive peaks at times \(t_1\) and \(t_1 + T_d\) (where \(T_d = 2\pi/\omega_d\) is the damped period):

\[u_1 = V\,e^{-\zeta\omega_n t_1}\cos(\omega_d t_1 - \psi)\] \[u_2 = V\,e^{-\zeta\omega_n(t_1+T_d)}\cos(\omega_d(t_1+T_d) - \psi)\]

Since at consecutive peaks the cosine has the same value, the ratio is:

\[\frac{u_1}{u_2} = \frac{e^{-\zeta\omega_n t_1}}{e^{-\zeta\omega_n(t_1+T_d)}} = e^{\zeta\omega_n T_d}\]

Taking the natural logarithm:

\[\delta = \ln\!\left(\frac{u_1}{u_2}\right) = \zeta\omega_n T_d = \zeta\omega_n \cdot \frac{2\pi}{\omega_d} = \frac{2\pi\zeta}{\sqrt{1-\zeta^2}}\]

ImportantLogarithmic Decrement

\[\boxed{\delta = \ln\!\left(\frac{u_1}{u_2}\right) = \frac{2\pi\zeta}{\sqrt{1-\zeta^2}}}\]

Measuring damping in practice: Record the free vibration signal, identify two peaks, and compute:

\[\zeta = \frac{\delta}{\sqrt{4\pi^2 + \delta^2}}\]

For small damping (\(\zeta \ll 1\)), \(\sqrt{1-\zeta^2} \approx 1\) and \(\delta \approx 2\pi\zeta\), so:

\[\zeta \approx \frac{\delta}{2\pi}\]

viewof zeta5 = Inputs.range([0.01, 2.5], {value: 0.1, step: 0.01, label: "Damping ratio  ζ"})
viewof wn5   = Inputs.range([0.5, 20],   {value: 5.0, step: 0.5,  label: "Natural frequency  ωₙ  (rad/s)"})
viewof u0_5  = Inputs.range([-3, 3],     {value: 1.0, step: 0.1,  label: "Initial displacement  u₀  (m)"})
viewof v0_5  = Inputs.range([-15, 15],   {value: 0.0, step: 0.5,  label: "Initial velocity  v₀  (m/s)"})
viewof show_envelope = Inputs.toggle({label: "Show decay envelope", value: true})
Code 
regime5 = zeta5 < 0.999 ? "underdamped" : (zeta5 < 1.001 ? "critical" : "overdamped")

// Time setup
tEnd5 = Math.max(5 * 2*Math.PI / Math.max(wn5 * Math.sqrt(Math.abs(1 - zeta5**2)), 0.1), 8 / (zeta5 * wn5))
tEnd5c = Math.min(tEnd5, 60)
dt5 = tEnd5c / 800

// Response function
function u5(t) {
  if (regime5 === "underdamped") {
    let wd = wn5 * Math.sqrt(1 - zeta5**2)
    let A5 = u0_5
    let B5 = (v0_5 + zeta5 * wn5 * u0_5) / wd
    return Math.exp(-zeta5 * wn5 * t) * (A5 * Math.cos(wd * t) + B5 * Math.sin(wd * t))
  } else if (regime5 === "critical") {
    let A5 = u0_5
    let B5 = v0_5 + wn5 * u0_5
    return (A5 + B5 * t) * Math.exp(-wn5 * t)
  } else {
    let sq = wn5 * Math.sqrt(zeta5**2 - 1)
    let s1 = -zeta5*wn5 + sq, s2 = -zeta5*wn5 - sq
    let A5 = (v0_5 - s2 * u0_5) / (s1 - s2)
    let B5 = u0_5 - A5
    return A5 * Math.exp(s1 * t) + B5 * Math.exp(s2 * t)
  }
}

function env5(t) {
  let V5 = Math.sqrt(u0_5**2 + ((v0_5 + zeta5*wn5*u0_5)/Math.max(wn5*Math.sqrt(1-zeta5**2),0.01))**2)
  return V5 * Math.exp(-zeta5 * wn5 * t)
}

t_arr5 = Array.from({length: 801}, (_, i) => i * dt5)
data5 = t_arr5.map(t => ({t, u: u5(t)}))
data5env_pos = (show_envelope && regime5 === "underdamped")
  ? t_arr5.map(t => ({t, y: env5(t)})) : []
data5env_neg = (show_envelope && regime5 === "underdamped")
  ? t_arr5.map(t => ({t, y: -env5(t)})) : []

// Logarithmic decrement (for underdamped)
delta5 = regime5 === "underdamped" ? 2 * Math.PI * zeta5 / Math.sqrt(1 - zeta5**2) : NaN
wd5 = regime5 === "underdamped" ? wn5 * Math.sqrt(1 - zeta5**2) : NaN
Td5 = regime5 === "underdamped" ? 2 * Math.PI / wd5 : NaN

Explore the three regimes:

  • Underdamped (\(\zeta < 1\)): Set \(\zeta = 0.05\)–\(0.3\). The system oscillates at \(\omega_d < \omega_n\), with an exponentially decaying envelope. The smaller \(\zeta\), the longer it takes to settle.
  • Critically damped (\(\zeta \approx 1\)): The system returns to zero the fastest possible without crossing the axis. Look for the zero crossing near \(t = 1/\omega_n\).
  • Overdamped (\(\zeta > 1\)): Two real decay rates give a sluggish, non-oscillatory return. Very large \(\zeta\) makes the system extremely slow.
  • Toggle envelope: For underdamped response, the dashed red lines show the exponential decay envelope \(\pm Ve^{-\zeta\omega_n t}\).
