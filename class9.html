Class 9 — Damped Tuned Vibration Absorber

Fundamentals of Mechanical Vibrations · Forced 2DOF Systems

9.1 From the Undamped Absorber to the Damped Absorber

In the previous class, we studied the undamped tuned vibration absorber. The system had a primary mass \(m_1\) connected to the ground by the stiffness \(k_1\), and an absorber mass \(m_2\) connected to the primary mass by the stiffness \(k_2\).

The purpose of the absorber was to reduce the vibration of the primary mass when a harmonic force acts on it:

\[F(t)=F_0\sin(\omega t)\]

For the undamped absorber, the equations of motion were:

\[m_1\ddot{u}_1+k_1u_1+k_2(u_1-u_2)=F_0\sin(\omega t)\]

\[m_2\ddot{u}_2+k_2(u_2-u_1)=0\]

Assuming harmonic response, we obtained the frequency response of the primary mass:

\[ \frac{U_1}{F_0} = \frac{k_2-m_2\omega^2} {(k_1+k_2-m_1\omega^2)(k_2-m_2\omega^2)-k_2^2}\]

The numerator becomes zero when

\[k_2-m_2\omega^2=0\]

therefore,

\[\boxed{\omega=\sqrt{\frac{k_2}{m_2}}}\]

At this frequency,

\[\boxed{U_1=0}\]

This is called antiresonance.

NoteMain idea from the previous class

The absorber mass moves in such a way that the force transmitted by the absorber spring cancels the external force applied to the primary mass. The primary mass does not move, even though the force is applied directly to it.

9.2 Why Do We Need Damping?

The undamped absorber gives a very impressive result: it can make the primary mass stop moving at one frequency.

However, this perfect cancellation occurs only when

\[\omega=\omega_a\]

where

\[\omega_a=\sqrt{\frac{k_2}{m_2}}\]

If the excitation frequency changes slightly, then

\[\omega\neq\omega_a\]

and the cancellation is no longer perfect.

There is also another problem. When we attach the absorber, the system becomes a 2DOF system. Therefore, instead of one natural frequency, the coupled system has two natural frequencies. These two natural frequencies create two resonance peaks around the tuned frequency.

So the undamped absorber has the following behavior:

\[\boxed{\text{Perfect cancellation at one frequency, but large amplitudes nearby.}}\]

In real machines, motors, turbines, pumps, compressors and rotating systems do not always operate at one perfectly fixed frequency. The speed may change during start-up, shut-down, or during normal operation.

Because of this, we add damping to the absorber.

ImportantEngineering trade-off

Adding damping removes the perfect zero of the undamped absorber, but it reduces the dangerous resonance peaks. This makes the absorber more robust.

9.3 Damped Tuned Vibration Absorber

Now we add a damper between the primary mass and the absorber mass.

The absorber is now composed of:

\[m_2, \qquad k_2, \qquad c_2\]

A simple schematic representation is:

The damping force depends on the relative velocity between the two masses:

\[\dot{u}_1-\dot{u}_2\]

Therefore, the damping force is proportional to

\[c_2(\dot{u}_1-\dot{u}_2)\]

Notice that the damper is not attached to the ground. It acts only when there is relative motion between \(m_1\) and \(m_2\).

If

\[\dot{u}_1=\dot{u}_2\]

then

\[c_2(\dot{u}_1-\dot{u}_2)=0\]

and the damper produces no force.

9.4 Equations of Motion

We take positive displacement to the right.

Mass 1

The forces acting on \(m_1\) are:

  • the restoring force from spring \(k_1\);
  • the spring force from \(k_2\);
  • the damping force from \(c_2\);
  • the external harmonic force \(F_0\sin(\omega t)\).

The equation is:

\[ m_1\ddot{u}_1 = -k_1u_1-k_2(u_1-u_2)-c_2(\dot{u}_1-\dot{u}_2)+F_0\sin(\omega t)\]

Rearranging:

\[\boxed{m_1\ddot{u}_1+k_1u_1+k_2(u_1-u_2)+c_2(\dot{u}_1-\dot{u}_2)=F_0\sin(\omega t)}\]

Mass 2

The absorber mass \(m_2\) is acted on only by the spring \(k_2\) and the damper \(c_2\).

The equation is:

\[m_2\ddot{u}_2=-k_2(u_2-u_1)-c_2(\dot{u}_2-\dot{u}_1)\]

Rearranging:

\[\boxed{m_2\ddot{u}_2+k_2(u_2-u_1)+c_2(\dot{u}_2-\dot{u}_1)=0}\]

Thus, the damped absorber equations are:

\[m_1\ddot{u}_1+k_1u_1+k_2(u_1-u_2)+c_2(\dot{u}_1-\dot{u}_2)=F_0\sin(\omega t)\]

\[m_2\ddot{u}_2+k_2(u_2-u_1)+c_2(\dot{u}_2-\dot{u}_1)=0\]

9.5 Harmonic Response with Damping

When damping is present, the displacement is generally not in phase with the force. For this reason, it is convenient to use complex notation.

We write the excitation force as:

\[F(t)=\operatorname{Re}\left\{F_0e^{i\omega t}\right\}\]

and assume the steady-state responses:

\[u_1(t)=\operatorname{Re}\left\{U_1e^{i\omega t}\right\}\]

\[u_2(t)=\operatorname{Re}\left\{U_2e^{i\omega t}\right\}\]

Here, \(U_1\) and \(U_2\) are complex amplitudes. They contain both amplitude and phase information.

For a harmonic term,

\[u(t)=Ue^{i\omega t}\]

we have:

\[\dot{u}(t)=i\omega Ue^{i\omega t}\]

\[\ddot{u}(t)=-\omega^2 Ue^{i\omega t}\]

Therefore, in the frequency domain, we can use the substitutions:

\[\boxed{u\rightarrow U}\]

\[\boxed{\dot{u}\rightarrow i\omega U}\]

\[\boxed{\ddot{u}\rightarrow -\omega^2 U}\]

NoteWhy complex numbers?

The physical motion is still real. The complex notation is only a mathematical tool. At the end, the physical amplitude is obtained from the magnitude \(|U|\).

9.6 Frequency-Domain Equations

Start with the first equation:

\[m_1\ddot{u}_1+k_1u_1+k_2(u_1-u_2)+c_2(\dot{u}_1-\dot{u}_2)=F_0\sin(\omega t)\]

Using the substitutions,

\[\ddot{u}_1\rightarrow -\omega^2U_1\]

\[\dot{u}_1\rightarrow i\omega U_1, \qquad \dot{u}_2\rightarrow i\omega U_2\]

we obtain:

\[-m_1\omega^2U_1+k_1U_1+k_2(U_1-U_2)+i\omega c_2(U_1-U_2)=F_0\]

Grouping the terms in \(U_1\) and \(U_2\):

\[\boxed{(k_1+k_2-m_1\omega^2+i\omega c_2)U_1-(k_2+i\omega c_2)U_2=F_0}\]

Now use the second equation:

\[m_2\ddot{u}_2+k_2(u_2-u_1)+c_2(\dot{u}_2-\dot{u}_1)=0\]

In the frequency domain:

\[-m_2\omega^2U_2+k_2(U_2-U_1)+i\omega c_2(U_2-U_1)=0\]

Grouping the terms:

\[\boxed{-(k_2+i\omega c_2)U_1+(k_2-m_2\omega^2+i\omega c_2)U_2=0}\]

The two algebraic equations are coupled, exactly as in the undamped case. The difference is that now the coefficients are complex.

9.7 Matrix Form

The frequency-domain equations can be written in matrix form as:

\[ \boxed{ \begin{bmatrix} k_1+k_2-m_1\omega^2+i\omega c_2 & -(k_2+i\omega c_2)\\ -(k_2+i\omega c_2) & k_2-m_2\omega^2+i\omega c_2 \end{bmatrix} \begin{bmatrix} U_1\\ U_2 \end{bmatrix} = \begin{bmatrix} F_0\\ 0 \end{bmatrix}} \]

This matrix is called the dynamic stiffness matrix.

It plays the same role as \(\mathbf{K}-\omega^2\mathbf{M}\) in the undamped free-vibration problem, but now it includes damping and external forcing.

ImportantDynamic stiffness

For forced harmonic vibration, the response is obtained from:

\[\mathbf{Z}(\omega)\mathbf{U}=\mathbf{F}\]

where \(\mathbf{Z}(\omega)\) is the dynamic stiffness matrix. It depends on the excitation frequency \(\omega\).

9.8 Complex Stiffness of the Absorber

To simplify the notation, define the complex stiffness of the absorber:

\[\boxed{Z_2=k_2+i\omega c_2}\]

This term contains both the elastic and dissipative effects of the absorber:

\[\text{spring contribution: } k_2\]

\[\text{damper contribution: } i\omega c_2\]

Using \(Z_2\), the system becomes:

\[ \boxed{ \begin{bmatrix} k_1+Z_2-m_1\omega^2 & -Z_2\\ -Z_2 & Z_2-m_2\omega^2 \end{bmatrix} \begin{bmatrix} U_1\\ U_2 \end{bmatrix} = \begin{bmatrix} F_0\\ 0 \end{bmatrix}} \]

This notation makes the damped absorber look almost identical to the undamped absorber. The only difference is that the stiffness \(k_2\) has been replaced by the complex stiffness \(Z_2\).

9.9 Solving for the Primary Mass Response

We want to obtain the frequency response of the primary mass:

\[\frac{U_1}{F_0}\]

From the second row of the matrix equation:

\[-Z_2U_1+(Z_2-m_2\omega^2)U_2=0\]

Move the first term to the right-hand side:

\[(Z_2-m_2\omega^2)U_2=Z_2U_1\]

Therefore:

\[\boxed{U_2=\frac{Z_2}{Z_2-m_2\omega^2}U_1}\]

Now substitute this relation into the first row:

\[(k_1+Z_2-m_1\omega^2)U_1-Z_2U_2=F_0\]

Substituting \(U_2\):

\[ (k_1+Z_2-m_1\omega^2)U_1 - Z_2\left(\frac{Z_2}{Z_2-m_2\omega^2}U_1\right) = F_0\]

Factor \(U_1\):

\[\left[(k_1+Z_2-m_1\omega^2)-\frac{Z_2^2}{Z_2-m_2\omega^2}\right]U_1=F_0\]

Put everything over the same denominator:

\[\left[\frac{(k_1+Z_2-m_1\omega^2)(Z_2-m_2\omega^2)-Z_2^2}{Z_2-m_2\omega^2}\right]U_1=F_0\]

Therefore:

\[ \boxed{ \frac{U_1}{F_0} = \frac{Z_2-m_2\omega^2} {(k_1+Z_2-m_1\omega^2)(Z_2-m_2\omega^2)-Z_2^2}} \]

Replacing \(Z_2=k_2+i\omega c_2\):

\[ \boxed{ \frac{U_1}{F_0} = \frac{k_2-m_2\omega^2+i\omega c_2} {(k_1+k_2-m_1\omega^2+i\omega c_2)(k_2-m_2\omega^2+i\omega c_2)-(k_2+i\omega c_2)^2}} \]

9.10 Response of the Absorber Mass

The same derivation also gives the response of the absorber mass \(m_2\).

We already found:

\[U_2=\frac{Z_2}{Z_2-m_2\omega^2}U_1\]

Using the expression for \(U_1/F_0\):

\[ \frac{U_1}{F_0} = \frac{Z_2-m_2\omega^2} {(k_1+Z_2-m_1\omega^2)(Z_2-m_2\omega^2)-Z_2^2}\]

we obtain:

\[ \boxed{ \frac{U_2}{F_0} = \frac{Z_2} {(k_1+Z_2-m_1\omega^2)(Z_2-m_2\omega^2)-Z_2^2}} \]

So both responses have the same denominator:

\[D(\omega)=(k_1+Z_2-m_1\omega^2)(Z_2-m_2\omega^2)-Z_2^2\]

The primary mass response is:

\[\frac{U_1}{F_0}=\frac{Z_2-m_2\omega^2}{D(\omega)}\]

The absorber mass response is:

\[\frac{U_2}{F_0}=\frac{Z_2}{D(\omega)}\]

NoteSame denominator, different numerators

Both masses have resonance peaks at the same frequencies because both responses have the same denominator. However, the antiresonance appears in the primary mass response because its numerator can become small.

9.11 What Happens to the Antiresonance?

For the undamped absorber,

\[c_2=0\]

and the numerator of \(U_1/F_0\) was:

\[k_2-m_2\omega^2\]

At

\[\omega=\sqrt{\frac{k_2}{m_2}}\]

this numerator became zero. Therefore,

\[U_1=0\]

This was the perfect antiresonance.

With damping,

\[c_2\neq 0\]

and the numerator becomes complex:

\[k_2-m_2\omega^2+i\omega c_2\]

The magnitude of this numerator is:

\[ \left|k_2-m_2\omega^2+i\omega c_2\right| = \sqrt{(k_2-m_2\omega^2)^2+(\omega c_2)^2}\]

This expression cannot become zero when \(c_2\neq 0\), because the term \((\omega c_2)^2\) is positive.

Therefore:

\[\boxed{\text{With damping, the antiresonance is no longer a perfect zero.}}\]

This may look like a disadvantage, but it is actually useful. Damping reduces the resonance peaks, making the system safer over a wider range of excitation frequencies.

9.12 Physical Interpretation

Let us compare the two cases.

Case 1: Undamped absorber

\[c_2=0\]

The primary mass has a perfect antiresonance:

\[U_1=0\]

at

\[\omega=\sqrt{\frac{k_2}{m_2}}\]

However, the resonance peaks around this frequency are very sharp.

Case 2: Damped absorber

\[c_2>0\]

The primary mass no longer reaches exactly zero amplitude. However, the resonance peaks become smaller.

Therefore, we exchange perfect cancellation at one frequency for better vibration reduction over a frequency band.

\[\boxed{\text{No damping: perfect cancellation, but sharp peaks.}}\]

\[\boxed{\text{With damping: no perfect cancellation, but lower peaks.}}\]

This is a common engineering compromise. We usually prefer a solution that is robust over a frequency range instead of a solution that is perfect only at one exact frequency.

9.13 Normalized Parameters

For design and plotting, it is useful to introduce normalized parameters.

The natural frequency of the primary system is:

\[\omega_1=\sqrt{\frac{k_1}{m_1}}\]

The absorber natural frequency is:

\[\omega_a=\sqrt{\frac{k_2}{m_2}}\]

The frequency ratio is:

\[r=\frac{\omega}{\omega_1}\]

The mass ratio is:

\[\mu=\frac{m_2}{m_1}\]

The tuning ratio is:

\[f=\frac{\omega_a}{\omega_1}\]

The damping ratio of the absorber is:

\[\zeta_2=\frac{c_2}{2m_2\omega_a}\]

Therefore,

\[\boxed{c_2=2\zeta_2m_2\omega_a}\]

responseData_9 = {
  const data = []
  const n = 1000
  const rMin = 0.2
  const rMax = 2.0

  for (let j = 0; j <= n; j++) {
    const r = rMin + (rMax - rMin) * j / n
    const omega = r * omega1_9

    // Complex absorber stiffness: Z2 = k2 + i omega c2
    const Zr = k2_9
    const Zi = omega * c2_9

    // A = k1 + Z2 - m1 omega²
    const Ar = k1_9 + Zr - m1_9 * omega**2
    const Ai = Zi

    // B = Z2 - m2 omega²
    const Br = Zr - m2_9 * omega**2
    const Bi = Zi

    // D = A*B - Z2²
    const ABr = Ar * Br - Ai * Bi
    const ABi = Ar * Bi + Ai * Br

    const Z2r = Zr * Zr - Zi * Zi
    const Z2i = 2 * Zr * Zi

    const Dr = ABr - Z2r
    const Di = ABi - Z2i

    const Dabs = Math.sqrt(Dr**2 + Di**2)

    // |U1/F0| = |B|/|D|
    const H1abs = Math.sqrt(Br**2 + Bi**2) / Dabs

    // |U2/F0| = |Z2|/|D|
    const H2abs = Math.sqrt(Zr**2 + Zi**2) / Dabs

    // Normalized amplitudes: k1 |U| / F0
    const A1 = k1_9 * H1abs / F0_9
    const A2 = k1_9 * H2abs / F0_9

    data.push({r: r, mass: "Primary mass  m₁", amplitude: Math.min(A1, ymax_9)})
    data.push({r: r, mass: "Absorber mass  m₂", amplitude: Math.min(A2, ymax_9)})
  }

  return data
}

9.14 Key Messages

  1. The undamped absorber can cancel the motion of the primary mass at one specific frequency.
  2. This cancellation is called antiresonance.
  3. The damped absorber is modeled by adding a damper \(c_2\) between \(m_1\) and \(m_2\).
  4. The damping force depends on relative velocity: \(c_2(\dot{u}_1-\dot{u}_2)\).
  5. With complex harmonic response, damping appears as \(i\omega c_2\).
  6. The absorber can be represented by the complex stiffness \(Z_2=k_2+i\omega c_2\).
  7. The primary mass response is:

\[ \frac{U_1}{F_0} = \frac{Z_2-m_2\omega^2} {(k_1+Z_2-m_1\omega^2)(Z_2-m_2\omega^2)-Z_2^2}\]

  1. The absorber mass response is:

\[ \frac{U_2}{F_0} = \frac{Z_2} {(k_1+Z_2-m_1\omega^2)(Z_2-m_2\omega^2)-Z_2^2}\]

  1. Adding damping removes the perfect zero, but reduces the resonance peaks.
  2. The damped absorber is more robust when the excitation frequency varies.
